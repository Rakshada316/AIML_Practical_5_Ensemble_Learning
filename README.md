# Practical Assignment 5: Ensemble Learning and Performance Evaluation

## 1. Introduction

This project implements different ensemble learning techniques using Python and Scikit-learn.

The main aim is to combine multiple machine learning classifiers and compare their performance with individual classifiers.

## 2. Objectives

- To implement Stacking Ensemble.
- To implement AdaBoost Ensemble.
- To implement Voting Ensemble.
- To compare different models using classification metrics.
- To understand the performance of ensemble learning techniques.

## 3. Dataset

**Breast Cancer Dataset**

The Breast Cancer dataset is a built-in dataset available in Scikit-learn. It is used for binary classification.

The dataset is loaded directly using Python, so no separate dataset download is required.

## 4. Algorithms Used

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Stacking Classifier
5. AdaBoost Classifier
6. Voting Classifier

## 5. Technologies and Libraries

- Python
- Google Colab / Jupyter Notebook
- Scikit-learn
- Pandas
- Matplotlib

## 6. Performance Evaluation

The models are evaluated using the following classification metrics:

- Accuracy
- Precision
- Recall
- F1-score

A comparison table and accuracy graph are generated to analyze the performance of the models.

## 7. Project Files

- `main.py` – Complete Python implementation.
- `README.md` – Project description and instructions.
- `requirements.txt` – Required Python libraries.

## 8. How to Run the Project

1. Download or clone this repository.
2. Install the required libraries using:

   `pip install -r requirements.txt`

3. Run the Python program:

   `python main.py`

4. View the performance comparison table, accuracy graph, and classification report.

## 9. Conclusion

This practical implements Stacking, AdaBoost, and Voting ensemble learning techniques. It compares these techniques with individual machine learning models using different classification metrics.

The practical helps in understanding how ensemble learning combines multiple classifiers to improve prediction performance.
